Challenges

One of the main challenges was maintaining smooth performance on lower-end Android devices while preserving the game's visual quality. Performance issues such as high draw calls, complex shaders, unoptimized 3D assets, inefficient object management, particle effects, and asset import issues from Maya to Unity required careful optimization to ensure a stable gameplay experience.

Solutions

  • Optimized 3D models by creating low-poly assets and applying mesh compression.
  • Reduced draw calls by reusing materials and combining static meshes./li>
  • Simplified shaders and minimized unnecessary lighting calculations.
  • Improved script performance by reducing unnecessary Update() calls, implementing object pooling, and optimizing object management.
  • Optimized particle effects to achieve smoother gameplay on mobile devices.
  • Use Mesh Combiner for the static objects

What I Learned

Through optimizing the game for mobile devices, I learned that achieving good performance requires balancing visual quality with efficiency. I gained hands-on experience in optimizing 3D assets, reducing draw calls, implementing object pooling, and writing more efficient scripts to improve frame rates and memory usage. I also learned the importance of maintaining a proper asset pipeline between Maya and Unity to avoid import issues and ensure a smoother development workflow. Most importantly, I realized that continuous profiling, testing, and optimization are essential for delivering a stable and enjoyable gameplay experience across different Android devices.
