Challenges

One of the biggest challenges was implementing touchscreen controls for mobile devices, as I had little experience with mobile input handling in Unity.

Solutions

I learned Unity's Input System by following tutorials and experimenting with different touch input techniques. Through testing and iteration, I successfully implemented responsive touchscreen controls for mobile gameplay.

What I Learned

This was my first mobile game project, and it taught me the fundamentals of mobile game development. I gained experience implementing touchscreen controls, designing user-friendly gameplay for mobile devices, and adapting Unity projects for a mobile platform.
